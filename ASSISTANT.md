# Помощник (офлайн-чат по документам клуба)

Страница `assistant.html` — «умный помощник», который отвечает на вопросы
игроков, опираясь на **документы клуба (PDF)**. Работает **полностью офлайн**,
**без API-ключей**, **без больших моделей** и **без интернета**.

## Как это устроено

1. **Индекс.** PDF разбирается и превращается в поисковый индекс
   `docs/assistant-index.json` (фрагменты текста + частоты терминов).
2. **Вопрос → ответ.** В браузере по запросу выполняется поиск (BM25 +
   морфологическая схожесть), находится самый подходящий фрагмент документа.
3. **Ответ = цитата из документа + ссылка на точное место.**
   Помощник показывает готовый фрагмент (связный текст из документа) и даёт
   ссылку на конкретную страницу PDF (например, `pravila-pestovo.pdf#page=2`).

Это **extractive RAG**: ответ собирается из слов самого документа, поэтому
он всегда корректен и «с цитатой». Если нужен именно *пересказ своими словами*
(генеративный, а не выдержка из текста) — это уже требует либо платного AI-API,
либо тяжёлой модели в браузере (~1–2 ГБ, WebGPU), что не совместимо с
«полным офлайном без больших загрузок». Выбранный вариант — оптимальный
компромисс.

## Файлы

| Файл | Назначение |
|------|-----------|
| `assistant.html` | Страница чата |
| `js/assistant.js` | Логика поиска и ответа (страница чата) |
| `js/assistant-build.js` | Общая библиотека сборки индекса (админка + чат) |
| `js/assistant-config.js` | Конфигурация (пути к индексу/PDF) |
| `docs/assistant-sources.json` | **Список базовых PDF** |
| `docs/assistant-index.json` | Готовый базовый поисковый индекс |
| `docs/*.pdf` | Сами документы |
| `vendor/pdfjs/*` | Копия pdf.js (для пересборки индекса в браузере) |
| `tools/build-assistant-index.js` | Сборка базового индекса (Node) |
| `tools/assistant-lib.js` | Общая логика токенизации/поиска (Node) |

## Как добавить свой PDF

### Вариант 1 — через админ-панель (без редактирования файлов)
Откройте **Админ-панель → вкладка «Помощник 🤖»**:
1. Введите **название документа** и **ссылку на PDF** (можно как внешний URL
   `https://…`, так и относительный путь `docs/mine.pdf`).
2. Нажмите **«Добавить»**, затем **«Сохранить и перестроить индекс»**.
3. Бот пересоберёт базу знаний (включая новые PDF) и сохранит её в Firebase —
   все игроки автоматически получат обновлённый помощник (он работает и офлайн).

Там же можно **скрыть страницу «Помощник» для всех** — снять галочку
«Скрыть страницу \<Помощник> для всех» и нажать «Сохранить». Страница исчезнет
из меню и будет недоступна игрокам (админ продолжает видеть её в админке).

### Вариант 2 — правкой файлов (для разработчика)
1. Положите файл в папку `docs/` (только `.pdf`, желательно с текстовым слоем).
2. Пропишите его в `docs/assistant-sources.json`:

   ```json
   {
     "name": "База знаний «Помощник Пестово»",
     "version": 1,
     "sources": [
       {
         "title": "Правила гольф-клуба «Пестово»",
         "file": "docs/pravila-pestovo.pdf",
         "description": "Регламент игр и услуг клуба"
       },
       {
         "title": "Регламент турниров",
         "file": "docs/reglament-turirov.pdf"
       }
     ]
   }
   ```

3. Пересоберите индекс:

   ```bash
   node tools/build-assistant-index.js
   ```

   (нужна установленная библиотека `pdfjs-dist`. Если её нет — `npm i pdfjs-dist`.)

4. Готово. Помощник автоматически найдёт и новые документы (индекс уже
   содержит их тексты). Все файлы — локальные, поэтому работают офлайн.

## Что ещё можно настроить

В `js/assistant.js` (вверху) можно изменить:
- количество показываемых фрагментов (`conf.maxChunks`),
- максимальный размер ответа (`conf.maxAnswerChars`).

## Замечания

- Важно, чтобы PDF содержал **текстовый слой** (а не были «картинками»).
  Если текст не извлекается — помощник не найдёт ответ.
- Если `assistant-index.json` отсутствует, помощник пересоберёт индекс
  прямо в браузере из PDF (нужен только локальный pdf.js, офлайн).
