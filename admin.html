Интеграция ВКонтакте (VK API)

При вызове судьи или маршала уведомление мгновенно отправится в вашу беседу или личные сообщения ВКонтакте.

Как получить токен сообщества
  1. Войдите в Управление сообществом → Работа с API → Ключи доступа
  2. Нажмите «Создать ключ», выберите права: Сообщения ✅
  3. Скопируйте полученный ключ (vk1.a.…) в поле ниже
  4. Peer ID беседы: откройте беседу ВК → ссылка вида vk.com/im?sel=c1 → Peer ID = 2000000001 (c + 2000000000)
  5. Peer ID пользователя: числовой ID из профиля ВКонтакте
  6. Добавьте сообщество в беседу и разрешите боту писать в настройках беседы
Для беседы: 2000000000 + номер чата. Для личных сообщений: ID пользователя.

Отправка выполняется напрямую через VK API (JSONP) без сторонних серверов. Версия API: 5.199.

Импорт игроков из Excel

Загрузите файл .xlsx / .xls / .csv — игроки появятся в списке игроков сайта. Дубликаты определяются по имени и фамилии: для них можно обновить точный гандикап.

Проверка гандикапа — база АГР России

Поиск точного гандикапа (HI) игрока в официальной базе Ассоциации гольфа России (hcp.rusgolf.ru) с возможностью добавить игрока к себе на сайт.

Проверка гандикапа из таблицы Excel

Загрузите таблицу Excel со списком игроков (столбцы Имя и Фамилия). Система найдёт каждого в базе АГР России и покажет список найденных результатов — отметьте нужных и добавьте их на сайт одним кликом.

Формы имён — «Наташа» = «Наталья»

На сайте игрок может быть записан коротким или иным вариантом имени (Наташа, Наталия, Natalia), а в базе АГР — полным. Выберите, как сопоставлять имена при поиске и синхронизации гандикапов. Словарь форм: js/name-variants.js.

Синхронизация гандикапов игроков

Проверяет точный гандикап всех зарегистрированных игроков, гостей и участников раундов в базе АГР России. Совпадение ищется по Фамилия + Имя и по Имя + Фамилия, а также по формам имени («Наташа» → «Наталья», «Наталия» — см. блок «Формы имён» выше). При однозначном совпадении HCP обновляется в профиле, раундах, истории и турнирах. В конце показываются списки: обновлено / актуально / не найдено / на выбор.

Настройки подключения (прокси к hcp.rusgolf.ru)

Сайт АГР не разрешает прямые запросы из браузера, поэтому используется цепочка публичных CORS-прокси. Если все прокси недоступны — укажите свой прокси-шаблон, где {url} будет заменён на адрес запроса.
Пример: https://my-proxy.example.com/?target={url}
