Интеграция Telegram: Группа Судей & Канал Клуба

Вы можете настроить отправку уведомлений отдельно для Группы Судей/Маршалов и для Канала Клуба (или использовать один и тот же бот).

1. Telegram Группа (Вызовы Судей и Маршалов)

💡 Добавьте бота в группу судей. Chat ID обычно начинается с -100...

2. Telegram Канал (Анонсы и Результаты)

💡 Назначьте бота Администратором канала с правом публикации сообщений. Укажите ID (-100...) или username (@pestovo_golf).

Интеграция ВКонтакте (VK API)

Укажите Токен доступа сообщества ВК и ID беседы/пользователя (Peer ID). При вызове судьи или маршала вызов мгновенно отравится в ваш чат ВК!

Отправить Push-анонс клуба

Сообщение будет отправлено на смартфоны всех зарегистрированных игроков клуба.
