# Журнал обновлений гандикапа

Вкладка «Журнал гандикапов» в админке показывает, **кто и когда** обновил гандикап игрока, старое и новое значение и источник изменения.

## Что записывается

Узел `hcpLog/{pushId}` в Realtime Database. Запись создаёт `pestovoLogHcpChange()` (`js/utils.js`).

| Поле | Значение |
|---|---|
| `at` | время записи (мс, `Date.now()`) |
| `actorUid` | uid пользователя, который внёс изменение (всегда текущий, правила не дают подставить чужой) |
| `actorName` | имя профиля автора (для мастер-пароля — «Мастер-пароль») |
| `actorRole` | `player`, `admin` или `master` |
| `playerName` | ФИО игрока, как его ввёл автор или как записано в RUSGOLF |
| `playerUid` | uid профиля игрока, если он есть |
| `oldHcp` | гандикап до изменения (отсутствует, если его не было) |
| `newHcp` | новый гандикап |
| `source` | источник: см. таблицу ниже |
| `note` | необязательная пометка |

Источники (`source`):

| Код | Когда пишется |
|---|---|
| `rusgolf-self` | игрок во время создания раунда ввёл своё имя и фамилию и нажал «RUSGOLF» на своей карточке; профиль (`users/{uid}`, `usersPublic`) сохранён |
| `manual-admin` | гандикап изменён вручную в админке (в том числе дубликат и добавление игрока) |
| `agr-admin` | синхронизация АГР из админки |
| `excel-import` | импорт Excel |

Ошибка записи в журнал не блокирует обновление гандикапа: в консоли появляется предупреждение `[hcp log]`.

## Что показывает вкладка

- **Последнее обновление по каждому игроку** — кто, когда и какое значение поставил.
- **История** — последние 500 записей, новые сверху. Поле поиска фильтрует по ФИО игрока или ФИО автора обновления.

## Правила доступа (`database.rules.json`)

- Чтение: только администраторы и мастер турниров (с действующим токеном `tournamentMaster`, как у `scoreAudit`).
- Запись: создание новой записи (`!data.exists()`), где `actorUid === auth.uid`, и проверка формы (типы полей, диапазон гандикапа −10…60, длины строк).
- Изменение и удаление записей запрещены.
- Индекс по `at` для выборки последних записей.

## Деплой

Журнал требует **нового правила БД**. Выкладывать вместе с клиентом:

```
firebase deploy --only database,hosting --project livescore-b77e4
```

Без деплоя правил запись в журнал не пройдёт (ошибка `PERMISSION_DENIED` в консоли), но сами обновления гандикапа работают.

## Проверка

`node tools/test-hcp-log.js` — запись журнала, поля автора, обновление своей карточки в создании раунда, ограничение «только свою карточку», таймаут RUSGOLF, отображение вкладки админки.
