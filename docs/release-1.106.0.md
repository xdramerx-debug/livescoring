# Версия 1.106.0 — печать форы, размеры по умолчанию, ресайз карточки, стартовый лист флайтами

Что вошло в релиз и как это проверить. Версия на сайте: футеры 13 страниц и
`CACHE_NAME` в `sw.js` обновлены (`npm run assets` проверяет `?v=` и кэш).

## 1. Черточки форы теперь печатаются

**Было:** наклонные палочки форы в клетках «Удары» рисовались через
`transform:rotate(25deg)`. На экране всё выглядело правильно, но ряд движков
печати при выводе PDF либо игнорирует трансформации, либо ужимает блок
`<i>` до нуля — в результате черточки видны только в превью, а на бумаге
клетка счёта пустая.

**Стало:** палочка рисуется через `linear-gradient(125deg, …)` — это
растр, а не трансформация. Один и тот же CSS отдаёт одинаковую картинку на
экране и на бумаге. Толщина увеличена с 0.3 мм до 0.5 мм, чтобы черточки
надёжно пропечатывались на любом принтере. Минусовая фора теперь задаётся
цветом родителя (`color:#a11414`), а палочка использует `currentColor` —
так не нужен отдельный селектор на дочерний элемент.

## 2. Размеры карточки по умолчанию для всех турниров

Карточка перешла в альбомную ориентацию и новый набор листовых параметров:

| Поле                | Было  | Стало      |
|---------------------|-------|------------|
| Ширина, мм          | 147   | **200**    |
| Высота, мм          | 200   | **147**    |
| X на листе, мм      | 90    | **105.86** |
| Y на листе, мм      | 40    | **39.68**  |
| Зазор, мм           | 3     | **17**     |
| Масштаб печати, %   | 140   | **120**    |

Размеры применяются к каждой карточке автоматически (панель
«Размеры — применяются ко всем карточкам сразу»). Если у турнира уже был
сохранён свой дизайн (`tournaments/<tid>/printScorecards`), он продолжает
работать без изменений — меняется только дефолт для новых турниров.

При этих параметрах в одну раскладку помещается ровно одна карточка; на
большом листе A4 landscape она автоматически вписывается через `pageFit()`.
Если нужны 2 карточки на лист — уменьшите «Масштаб печати» (например, до
70 %) или зазор (до 3 мм).

## 3. Растягивание карточки прямо в редакторе

Раньше карточку можно было только двигать мышью за ручку ✥. Размер жил в
полях «Ширина/Высота» панели размеров. Теперь у карточки появились 8
ручек по периметру (4 угловые + 4 боковые). Тянем за любую — карточка
растёт/уменьшается с этой стороны, противоположная грань остаётся на
месте. Числа в панели размеров и на бумаге обновляются синхронно.

Ручки появляются только в режиме «лист A4» (в режиме «только карточка»
они лишние — карточка уже подогнана под окно).

## 4. Стартовый лист в админке: режим «Флайтами»

В админ-панели на вкладке «Стартовый лист» теперь два режима показа:

- **Флайтами** (по умолчанию): участники сгруппированы по флайтам.
  Флайты идут по порядку стартовой лунки: 1А → 1Б → 2А → 2Б → …
  Свёрнутый флайт — компактная карточка с номером, стартовой лункой,
  временем и составом (имена игроков через запятую). Клик разворачивает
  обычную таблицу со всеми колонками. Состояние раскрытого флайта
  запоминается при перерисовке.
- **Списком**: старая плоская таблица — для тех, кому так привычнее.

PDF и Excel выгрузки тоже отсортированы по флайтам/лункам (1А, 1Б, 2А,
…), а не по полю `order`. Это совпадает с печатной вёрсткой и помогает,
когда админ вручную менял порядок строк.

## Как проверить

1. Карточки любого турнира: «Распечатать все» → в PDF палочки форы видны
   в клетках счёта (раньше были только в превью).
2. Создать новый турнир, открыть «Счетные карточки» → размеры по
   умолчанию 200×147, 105.86/39.68, зазор 17, масштаб 120. Тянем за
   угол карточки → поля в «Размеры» обновляются, превью и будущая
   печать — совпадают.
3. «Стартовый лист» → переключатель «Флайтами / Списком» →
   флайты идут по лункам, свёрнутые показывают номер, лунку и состав,
   разворачиваются кликом.

## Файлы

- `js/tn-mgr-printcards.js` — дефолты размеров, `linear-gradient` для
  палочек форы, 8 ручек растягивания на карточке;
- `css/tn-mgr-printcards.css` — стили ручек ресайза, скрытие их при
  печати и в режиме «только карточка»;
- `js/tn-mgr-sheet.js` — режим «Флайтами» в админке, флайт-«аккордеоны»,
  переключатель вида;
- `css/tn-manager.css` — стили флайт-карточек;
- `js/tn-mgr-core.js` — сортировка PDF/Excel листа по флайтам/лункам;
- `tools/test-tn-mgr-printcards.js` — обновлены ожидания для дефолтов
  размера/раскладки и для проверки «палочки наклонные» (теперь
  `linear-gradient(125deg)`).
