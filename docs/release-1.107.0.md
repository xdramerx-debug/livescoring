# Версия 1.107.0 — растягиваемые блоки карточки, длина лунок, цвета и шрифты

Что вошло в релиз и как это проверить. Версия на сайте: футеры 13 страниц и
`CACHE_NAME` в `sw.js` обновлены (`npm run assets` проверяет `?v=` и кэш).

## 1. Блоки таблицы растягиваются мышью

**Было:** все строки таблицы карточки (№, Пар, Индекс, Фора, Удары) жили в
одной таблице с общими кеглем, высотой и колонкой подписи — увеличить, скажем,
только «Удары» было нельзя.

**Стало:** каждая строка — самостоятельный блок `<div class="tnpc-block">` со
своей мини-таблицей и CSS-переменными (`--tnpc-table`, `--tnpc-row-h`,
`--tnpc-lab-w`). Пока у блока нет своих значений, они наследуются от общих
размеров панели «Размеры и место на листе» — старые дизайны выглядят как раньше.
У каждого блока три золотые ручки прямо на карточке:

| Ручка | Что делает |
|---|---|
| ↕ (низ по центру) | высота строк блока |
| ↔ (левый край) | ширина колонки подписи («Удары», «Пар»…) |
| ↘ (правый нижний угол) | весь блок разом: кегль + высота + подпись пропорционально |

Растягивание применяется к предпросмотру без перерисовки (плавно), числа в
панели следуют за мышью, сохранение — как у остальных правок дизайна
(`printScorecards/rows/<block>`), одна правка меняет все карточки турнира.
Двойной клик по блоку открывает его настройки в панели «Цвет и шрифт».
Соседние блоки соприкасаются одной линией (следующая подтянута на толщину
линии), ручки на печать и в PDF не попадают.

## 2. Строка «Длина, м»

Новая строка таблицы — длина лунок в метрах (стоит после «Пар», до
«Индекса»):

- значения по умолчанию — из справочника поля (белые ТИ), кнопки
  «Заполнить по ТИ» (Белые / Синие / Чёрные / Красные) заполняют все 18 лунок;
- правится прямо в клетках карточки (клик по клетке) или числами в панели
  «Лунки, пар, длина, индекс»; 0 = пустая клетка;
- итоги OUT/IN/TOTAL считают только заполненные клетки;
- включается/выключается галочкой «Строка «Длина» (метры)» в «Составе
  информации»;
- у турниров, сохранённых до этой версии, строка появляется автоматически на
  своём месте: `normalizeRowOrder()` вставляет новые строки канонически, не
  двигая сохранённый порядок остальных.

## 3. Панель «Цвет и шрифт»

Новая пятая панель редактора (иконка 🎨):

- **Общее:** шрифт всей карточки (Arial по умолчанию + Georgia, Times New
  Roman, Verdana, Tahoma, Trebuchet MS, Courier New, Impact, системный), цвет
  текста, фон карточки, цвет линий, фон колонок OUT/IN/TOTAL.
- **Каждый блок:** свой кегль/высота/колонка подписи, цвет текста, фон,
  шрифт и полужирный (красятся клетки, подпись и черточки форы вместе);
  кнопки «✕» у цветов и «Как у всех» возвращают наследование от общих
  значений.
- Всё применяется живьём, без перерисовки вкладки и потери фокуса. Цвета
  хранятся hex-значениями и валидируются при загрузке (`validColor`), шрифт —
  только из списка (`safeFont`), поэтому сохранённые данные не могут сломать
  разметку карточки.

## Как проверить

1. Админка → «Турниры 🏆» → турнир → «Счетные карточки» → панель
   «Цвет и шрифт»: смените цвет текста и фон карточки — предпросмотр красится
   сразу, печать («Печать всех») даёт те же цвета.
2. Потяните блок «Удары» за ручку ↘ — кегль, высота и подпись растут вместе;
   потяните «Пар» за ↕ — растёт только высота. Числа в панели «Цвет и шрифт»
   следуют за мышью, после перезагрузки страницы размеры сохранены.
3. Строка «Длина, м» видна на карточке; нажмите «Заполнить по ТИ: Красные» —
   значения пересчитаются; снимите галочку «Строка «Длина»» в «Составе
   информации» — строка исчезнет.
4. Двойной клик по любому блоку — панель «Цвет и шрифт» открывается и
   подсвечивает настройки этого блока.
5. `npm test` — 144 проверки конструктора печати + 18 DOM-проверок блоков
   (jsdom); `npm run check:printcards` — живая браузерная проверка
   (растягивание блока, панель «Цвет и шрифт», строка «Длина»).

- `js/tn-mgr-printcards.js` — блоки таблицы с своими размерами/цветом/шрифтом,
  ручки растягивания ↕/↔/↘, строка «Длина» + заполнение по ТИ, панель
  «Цвет и шрифт», переменные дизайна `--tnpc-ink/paper/linec/sumbg/font`,
  каноническая вставка новых строк в `normalizeRowOrder()`;

  «Цвет и шрифт», скрытие ручек при печати;
- `tools/test-tn-mgr-printcards.js` — обновлены ожидания порядка строк и
  переменных, добавлены проверки длин, блоков, дизайна и цветов;
- `tools/test-tn-mgr-printcards-ui.js` — новый DOM-тест (jsdom): разметка
  блоков, ручки, живые правки, растягивание pointer-событиями, печать;
- `tools/check-printcards-preview.js` — браузерная проверка дополнена блоками,

  дефолтов 120% / 105.86×39.68 и позиций черточек 0.15 мм);
- `docs/tn-manager.md` — раздел 6 переписан под новые возможности.
