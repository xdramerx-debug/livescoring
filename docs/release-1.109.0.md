# Версия 1.109.0 — длина лунок по ТИ карточки

Что вошло в релиз и как это проверить. Версия на сайте: футеры страниц и
`CACHE_NAME` в `sw.js` обновлены (`npm run assets` проверяет `?v=` и кэш).

## 1. Длина лунок зависит от ТИ карточки

**Было:** во вкладке «Счетные карточки» строка «Длина, м» была одна на весь
турнир (`draft.lengths`) — одинаковая для всех карточек, независимо от того,
с каких ТИ играют игроки в стартовом листе.

**Стало:** строка «Длина» берётся по ТИ игрока из стартового листа
(`card.tees[i]`, либо ручная правка ТИ на карточке):

- ТИ из справочника (`HOLES` в `js/course-config.js`: чёрные, синие, белые,
  красные) — длины этого ТИ; ряд только для чтения;
- связка с разными ТИ — по строке «Длина» на каждый ТИ, с подписью ТИ;
- ТИ не выбран или не из справочника — запасной ряд из панели «Лунки, пары,
  длина, индекс и фора», как раньше; его по-прежнему можно править в клетках
  и заполнять кнопками «Заполнить запасной ряд по ТИ».

## Проверка

1. Откройте турнир → «Стартовый лист»: у двух игроков выберите разные ТИ
   (например, белые и красные).
2. Откройте «Счетные карточки»: у каждой карточки строка «Длина» показывает
   свой ТИ (лунка 1: белые — 328 м, красные — 317 м).
3. Смените ТИ игрока в стартовом листе — длина на карточке обновится.
4. Печать/PDF: значения совпадают с предпросмотром.

Автотесты: `tools/test-tn-mgr-printcards-ui.js` (длины по ТИ, смена ТИ,
запасной ряд, печать).
