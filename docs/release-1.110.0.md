# Версия 1.110.0 — отдельные флайты и персональный QR игрока

## Стартовый лист

При последовательном старте каждая стартовая группа получает собственный
номер флайта: 1, 2, 3 и далее. Раньше номер вычислялся по стартовой лунке,
поэтому все группы с одной лунки отображались внутри «Флайта 1».

Сбалансированное распределение игроков сохраняется: при размере группы 4
получаются, например, 4+3 для 7 игроков и 4+3+3 для 10. Нумерация не зависит
от выбранной стартовой лунки. Шотган и обозначения волн 1А/1Б не изменены.
Для маленьких составов, которые невозможно разбить на группы по 3–4,
сохраняется существующее поведение генератора.

## QR на карточке

Персональный QR открывает реальный раунд группы от имени **игрока карточки**:
его идентификатор передаётся в `as` (или `player` для одиночного ввода).
Поэтому ФИО в поле «Я» соответствует игроку, а не назначенному ему маркеру.
Назначения маркеров и возможность вести счёт партнёра не меняются.

- Одинаковая привязка используется в редакторе карточек, печати, QR-панели
  стартового листа и карточках раунда.
- Ссылка строится заново из актуальных идентификаторов: старый сохранённый
  QR маркера больше не подменяет игрока при повторной печати.
- У парной карточки QR-блоки соответствуют игрокам по порядку.
- Уже распечатанные старые QR-коды нужно перепечатать: их содержимое
  не меняется при обновлении сайта.

## Проверка

1. Создать последовательный стартовый лист на 10 участников с размером
   группы 4: должны получиться три флайта по 4, 3 и 3 игрока.
2. Повторить со стартом с 10-й лунки: флайты остаются 1, 2, 3;
   стартовая лунка у всех — 10. Проверить печатный стартовый лист.
3. Добавить QR к карточке игрока, у которого назначен другой игрок маркером.
   После сканирования проверить раунд и ФИО в поле «Я».
4. Проверить повторную печать карточки старого листа со ссылкой маркера,
   а также парную карточку с двумя QR.

Обновлены футеры сайта, версии изменённых ассетов и кэш service worker.
Регрессионные проверки: `test-tn-mgr-core`, `test-tn-mgr-sheet-publish`,
`test-tn-mgr-printcards`, `test-tn-mgr-ui`, `check-printcards-preview`.
