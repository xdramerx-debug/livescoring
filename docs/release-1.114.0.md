# Версия 1.114.0 — счётные карточки на экране ввода результата

## Карточки на странице ввода результата (setup-round.html)

- Два вида карточки, у каждого 5 вариантов оформления:
  - «Общая карточка» (группа из 2+ игроков): «Таблица клуба», «Блоки по 9»,
    «Строки игроков», «Карточки игроков», «Плитки лунок»;
  - «Счётная карточка по лункам» (один игрок, соло и турнирный QR): «Бланк клуба»,
    «Тройки», «Лента», «Список», «Плитки».
- Размеры s / m / l; элементы показа включаются и выключаются по отдельности.
- Новая вкладка админки «Карточки на вводе 🃏»: выбор вида, размера и элементов,
  отдельный вид для турнирного ввода. Превью на демо-данных не пишет в базу;
  «Применить для всех» сохраняет настройки в `settings/entry_scorecard_display`,
  открытые экраны обновляются сразу.

Остальные страницы (главная, лидерборды, история, печать) оформление не меняют.

Проверки: `node tools/test-entry-scorecard.js`, `npm run check:entry-scorecards`.
Подробности: `docs/scorecard-display.md`.
