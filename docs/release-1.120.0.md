# Версия 1.120.0 — визуальный слой: одна палитра, читаемые размеры, светлая тема

Оформление игровых страниц переведено на слой `css/theme-v2.css`, который
подключается сразу после `css/style.css` и до `css/design-presets.css`.
Шаблоны оформления из админки по-прежнему перебивают его, база `style.css`
не переписана — правки сосредоточены в одном файле.

## Что изменилось на экране

- **Поверхности и границы.** Карточки, плитки, поля ввода и таблицы получили
  видимую шкалу: фон → карточка → вложенный блок, границы полей контрастнее
  3:1 (в исходной теме карточка отличалась от фона на 1.09:1, а рамка
  поля — на 1.36:1, то есть объекты «растворялись» в фоне).
- **Палитра.** Латунь (`#d8b263`) вместо жёлтого золота; заголовки белые,
  золото осталось у главной кнопки, живого счёта и активного пункта меню.
- **Типографика.** Inter 800 теперь реально загружается (в CSS 122 объявления
  `font-weight: 800` + 18 `900`, а Google Fonts отдавал только 300–700 —
  цифры рисовались синтетическим болдом). Подписи подняты до 11–12 px вместо
  9–10, кнопки и заголовки — к шкале 12/13.5/15/18/clamp(22…28).
- **Первый экран.** Hero занимает не весь экран (`clamp(400px, 62svh, 560px)`),
  логотип 116 px на десктопе и 104–140 px на телефоне: «Сейчас на поле»
  попадает в первый экран.
- **Кнопки.** Один вариант акцента вместо трёхстопового градиента с тенью и
  сдвигом одновременно; капс на кнопках убран; высоты 42/34/50 px, на
  телефоне 44 px — под палец.
- **Статусы.** Сверка счёта и состояния лунок различаются не только цветом:
  добавлены иконки и форма рамки (пунктир у «не совпало»), мигание фона
  заменено пульсацией рамки.
- **Поле клуба.** Матрица 11 колонок больше не сжимается до 8 px: 10 px в
  ячейках, 360 px хватает без обрезки, на 320–340 px карточка прокручивается
  вбок вместо микро-кегля.
- **Светлая тема («Солнце»).** Тёплый белый фон, серо-зелёные hairline вместо
  чёрных рамок в 2 px, тёмная латунь как акцент (`#8a6a1f` — 5.09:1 на белом).
  Контраст текста сохранён, стеклянные блюры отключены.

## Проверки

- `tools/test-design-tokens.js` (`npm run check:design`, шаг в CI) считает
  контраст пар токенов по WCAG 2.x для тёмной и светлой темы, проверяет
  минимальный кегль, наличие токенов светлой темы, порядок подключения слоя
  на всех страницах и загрузку Inter 800.
- `npm test` — 85/85; `npm run lint`, `check:fonts`, `check:bundle`,
  `rev-assets --check`, `test-sw-precache` — зелёные.
- Браузерные проверки на реальном Chromium: `check:browser` (15 страниц,
  classic и bundle идентичны), `check:nav`, `check:round-setup-mobile`,
  `check:tournaments-mobile`, `check:admin-display-mobile`,
  `check:scorecards`, `check:printcards`, `check:scorecard-pwa` — пройдены.
