# Версия 1.124.0 — админка на телефоне, импорт 5000 игроков, свои шрифты

## Зачем

Админ-панель на телефоне открывалась с ~2 МБ скриптов (турниры, Excel, RUSGOLF,
конструктор карточек), даже если нужны только вызовы судьи. Импорт состава
турнира из Excel на 5000+ строк подвешивал вкладку: каждый игрок писал в
Firebase отдельно и перечитывал весь состав. Google Fonts не кэшировались
service worker’ом на поле.

## Что изменилось

1. **Импорт участников турнира.** `addPlayers` пишет пакетами (`writeInChunks`),
   между порциями отдаёт кадр UI. Предпросмотр показывает первые 40 строк,
   список участников — по 80 на страницу. Excel-библиотека грузится по запросу.
2. **Админка: 5 разделов вместо 19 вкладок.** Смена / Турниры / Игроки /
   Оформление / Система. Тяжёлые скрипты подключаются при первом заходе
   на вкладку (`js/admin-lazy.js`). SheetJS больше не в первом экране.
3. **Главная на телефоне.** Hero больше не занимает 100svh, логотип 96 px,
   подписи не мельче 12 px.
4. **Шрифты Inter и Playfair** лежат в `fonts/` (`css/fonts-local.css`),
   без fonts.googleapis.com.
5. **HTML счётных карточек** вынесен в `js/utils-scorecards.js` (после `utils.js`).
