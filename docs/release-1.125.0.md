# Версия 1.125.0 — экран лунки, табло-TV, живая главная

## Зачем

На поле ввод счёта был сайтом с меню и мелкими +/−. GitHub Pages
(`xdramerx-debug.github.io/livescoring`) не обновлялся после 1.124.0:
Firebase выкатывался, Pages — нет.

## Что изменилось

1. **Клавиатура 1…10 и «Пар»** на карточке игрока, маркера и группового ввода.
2. **Подтверждение странного счёта** (ace, ≥ пар+3, ≥ 8).
3. **Отмена последней лунки** и кнопка «Крупно».
4. **Вызов судьи/маршала** спрятан за «Ещё» — меньше случайных нажатий.
5. **Киоск по QR:** пункты меню скрыты, цифра счёта 64 px, альбом для тележки.
6. **Офлайн-бейдж** на всю ширину: «N ударов ждут сеть».
7. **Главная:** сначала мои раунды и кто на поле, hero ниже.
8. **Табло TV:** `leaderboard.html?tv=1` без меню, крупные строки.
9. **Светлая тема** днём, если пользователь сам не выбрал тему.
10. **GitHub Pages** собирается из `public/` при push в `arena/01a02acd-livescoring`.

Деплой: Hosting (Firebase) + Pages после мержа в дефолтную ветку.
