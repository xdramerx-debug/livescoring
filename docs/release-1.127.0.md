# Версия 1.127.0 — один раунд: единая страница, единое создание, единый ввод счёта

1. **Одна страница вместо двух подсистем.** Одиночный раунд больше не имеет
   собственного экрана (`#game`, `#read-only-view`). И одиночный, и групповой
   раунд открываются на `setup-round.html` в общем экране `#active-scoring-view`
   (ввод) и `#group-view` (просмотр).
2. **Единое создание раунда.** Форма `js/round-setup.js` одна; точка входа тоже
   одна — `pestovoCreateRound()` в `js/live.js`. Режим выводится из состава:
   1 игрок → `mode='solo'`, 2+ → `mode='group'` (маркеры по кругу). Старые имена
   `startSolo()`/`startGroup()` остались обёртками для совместимости.
3. **Единый ввод результатов.** `saveHoleScores()` пишет счёт для любого состава:
   в соло — только свой счёт (без marker-операций) и сразу `verified=true`,
   в группе — двойной ввод и подтверждение обеими сторонами. Тост «ждём маркера»
   в соло не показывается.
4. **Единая проверка лунок.** `getHoleVerifyState()` считает введённый счёт
   подтверждённым, если маркера нет (`!markedBy`), — лента лунок в соло больше не
   висит серой и раунд можно завершить. То же правило продублировано на сервере
   (`functions/score-audit.js`) и в офлайн-фолбэке (`js/score-write.js`).
5. **Функции соло переехали в общий экран:** дедлайн лунки, строка данных раунда
   (игрок, HCP, ТИ, формат, старт), темп игры, пауза, принудительное завершение,
   вызов судьи/маршала, счётная карточка. Для одиночного раунда скрываются только
   панель маркера и QR-подключения (подключать некого).
6. **`js/solo.js` стал слоем совместимости** (~60 строк вместо 1272): собственной
   логики ввода счёта и записи в базу в нём больше нет. Удалены дубли
   `buildHoles`, `saveSolo`, `finishSolo`, `callOfficialSolo`, `renderMiniCard`,
   `renderRoundInfo` и т.п.
7. **Регрессии закрыты тестами:** новый `tools/test-unified-round-page.js`
   (соло-раунд в общем экране: одна операция записи, `verified=true`, переход на
   следующую лунку, отсутствие «ждём маркера», незаблокированное завершение),
   плюс соло-кейс в `tools/test-score-audit.js`.
8. **Проверено в реальном Chromium** (headless, через `@sparticuz/chromium` +
   заглушки NSS: `bash tools/build-stub-libs.sh`, `CHROMIUM_EXTRA_LIBS=$PWD/tools/.browser-stub`):
   `tools/check-round-setup-mobile.js` — 798 проверок единой формы на 7 ширинах;
   `tools/check-score-entry-mobile.js` — единый ввод счёта на 320–768 px в трёх
   режимах (группа, соло-копия того же экрана, QR-турнир);
   `tools/check-scoring-header-mobile.js` — компактные заголовки и QR;
   `tools/browser-check.js` — все 13 страниц, варианты classic и bundle идентичны.
   `check-score-entry-mobile.js` обновлён: в `setup-round.html` остался один
   `.score-entry` (второй — на `scorer.html`), поэтому «соло» в проверке —
   клон единого экрана.
