# Версия 1.130.2 — убран приветственный оверлей на главной

Патч-релиз: с главной убран модальный экран «Пестово — live-скоринг»
(«Смотреть live / Начать раунд / Таблица лидеров / Пропустить»).

## Почему

Оверлей показывался при каждом первом визите на устройстве и закрывал ровно
то, ради чего открывают главную, — список live-раундов. Внутри самого
оверлея первая кнопка называлась «Смотреть live», то есть предлагала
закрыть его и посмотреть то, что и так было бы видно. На телефоне карточка
занимает почти весь экран: чтобы увидеть счёт, нужно было сделать лишний
тап.

## Что удалено

| Файл | Что ушло |
|---|---|
| `js/product-ux.js` | `buildOnboarding()`, `onboardingSeen()`, `markOnboardingSeen()`, `ONBOARDING_KEY`, вызов в `boot()`, поле `onboardingKey` в публичном `pvUx` |
| `css/product-ux.css` | блок «Онбординг на один экран» (`.pv-onb*`, 11 правил), правила light-темы для `.pv-onb*`, `.pv-onb-action` из группы тач-таргетов |
| `js/i18n.js`, `src/i18n.js` | 7 ключей `pv_onb_*` в ru и en (14 строк в каждом файле) |
| `README.md` | упоминание онбординга в описании продуктового слоя |

Нижняя навигация, чипы фильтров, баннер «нет сети», шаги создания раунда и
sticky-CTA не затронуты — удалён только модальный экран.

статических:

`js/utils-scorecards.js`. Тест снова проходит целиком — то есть его 77
проверок теперь реально что-то проверяют.
