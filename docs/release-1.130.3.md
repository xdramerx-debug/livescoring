# Версия 1.130.3 — с героя убрана пометка «Тестовая версия · демо-данные»

Патч-релиз: с первого экрана главной убрана плашка
«🧪 Тестовая версия · демо-данные».

## Почему

Плашка стояла в герое между строкой «18 лунок · Пар 72» и кнопками
«Начать игру / Все раунды» — то есть на самом дорогом месте страницы, внутри
первого экрана. Читается она при этом как часть оффера («это тест, играть
всерьёз нельзя»), а не как честная пометка данных: демо-раунды и так
помечены статусом на самих карточках («Тестовый раунд»), и там эта пометка
уместна — она относится к конкретным данным, а не ко всему сайту.

## Что изменено

| Файл | Правка |
|---|---|
| `index.html` | удалён блок `<p class="hero-demo">…` |
| `css/product-ux.css` | удалены `body.pv-ux .hero-demo` и блок «Пометка демо-версии» (`.pv-demo`, `.pv-demo i`) |
| `js/i18n.js`, `src/i18n.js` | удалён ключ `pv_demo_badge` (ru и en) |
| `css/product-ux.css` | `body.pv-ux .hero-btns { margin-top: 18px }` — вместо удалённой плашки |

Правка отступа не косметическая: плашка занимала в потоке 26 px + 18 px
отступа, и после её удаления на телефоне кнопки прилипали к строке
«18 лунок · Пар 72» (там `.hero-desc` имеет `margin-bottom: 10px`
в мобильном блоке `style.css`). Теперь расстояние 18 px и на телефоне,
и на десктопе (вертикальные отступы соседей схлопываются по максимуму).
Проверено замером в браузере: 10 → **18 px**.

## Гейты

`tools/test-product-ux.js`: **77 → 79** проверок.
Прежняя проверка «пометка тестовой версии видна» заменена на обратные:

* `index.html` не содержит ни `pv_demo_badge`, ни класса `pv-demo`;
* `css/product-ux.css` не содержит стилей `.pv-demo`;
* ключа `pv_demo_badge` нет ни в `js/i18n.js`, ни в `src/i18n.js`.

## Побочный эффект: сабсет иконок стал меньше

Вместе с плашкой с главной ушла иконка `fa-flask`, и сборщик сабсета
(`npm run build:fonts`) пересобрал шрифт: `fonts/fa-solid-900-subset-*.woff2`
получил новый хеш, старый файл удалён. Это не ручная правка — так работает
`tools/build-fontawesome.js`: набор иконок считается по факту использования
в разметке.
