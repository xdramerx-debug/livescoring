# Версия 1.141.0 — пин-позиция лунки на экране ввода счёта

Игрок стоит на грине и хочет видеть, куда поставили флажок. Раньше за этим
нужно было либо идти смотреть, либо спрашивать маркера. Теперь положение
флажка на каждой лунке задаёт администратор, а игрок открывает его одним
свайпом прямо на экране ввода счёта — не уходя с карточки и не трогая
клавиатуру счёта.

## Что видит игрок

| Состояние | Как выглядит | Как управляется |
|---|---|---|
| Свёрнуто (по умолчанию) | Закладка у правого края: флажок и номер лунки | Свайп влево по закладке или тап |
| Развёрнуто | Панель со схемой грина, отметкой флажка, подписью зоны, подсказкой на лунку и общей подсказкой раунда | Свайп вправо, кнопка «Свернуть», крестик, `Esc`, тап мимо панели |

Закладка живёт в фиксированном контейнере (`.pin-panel`), поэтому раскрытие
панели **не сдвигает** ленту лунок и клавиатуру счёта: ввод счёта остаётся
на месте, панель просто ложится поверх. Это главное требование к фиче —
посмотреть флажок и вернуться к вводу за пару секунд.

Где именно:

- `scorer.html` — одиночная карточка игрока (`#sc-pin-panel`);
- `setup-round.html` — экран ввода группового/одиночного раунда
  (`#play-pin-panel`, внутри `#active-scoring-view`);
- `marker.html` — карточка маркера (`#mk-pin-panel`).

Смена лунки не сбрасывает виджет: панель остаётся в том же состоянии
(свёрнута/развёрнута) и перерисовывает схему под новую лунку. Лунка
передаётся из рендера шапки (`js/scorer.js`, `js/marker.js`, `js/live.js` →
`pestovoPinPanelHole(source, hole)`).

## Что настраивает администратор

Админ-панель → вкладка «Пин-позиции» (`#tab-pinpositions`,
`js/admin-pin-positions.js`, грузится лениво через `js/admin-lazy.js`):

- переключатель «Показывать пин-позицию игрокам» (выключен — закладки нет ни
  на одном экране, например пока флажки не расставлены);
- сетка из 18 кнопок лунок с точкой текущего положения флажка;
- зона грина: девять клеток 3×3 — `Дальняя левая / Дальняя середина /
  Дальняя правая`, `Середина слева / Центр грина / Середина справа`,
  `Ближняя левая / Ближняя середина / Ближняя правая`;
- заметка к лунке (до 120 символов) — «Флажок за бункером, ветер слева»;
- общая подсказка на раунд (до 280 символов), показывается, если у лунки нет
  своей заметки;
- живое превью «как увидит игрок»;
- «Сохранить пин-позиции» и «Все лунки — в центр» (сброс);
- индикатор «Есть несохранённые изменения».

## Хранение

```
settings/pin_positions = {
  enabled: true,
  note: "…",            // ≤ 280
  updatedAt: <ms>,
  updatedBy: "<имя>",
  holes: { "7": { zone: "bl", note: "…" } }   // только изменённые лунки, note ≤ 120
}
```

- Читают все: `settings` в `database.rules.json` открыт на чтение (это
  публичные данные раунда, как `scoring_display`).
- Пишет только администратор — отдельного правила не потребовалось, запись
  идёт под общей веткой `settings` с существующими правами.
- Отсутствие лунки в `holes` = центр грина (`mc`), поэтому база не растёт от
  «ничего не меняли»: сохраняются только реально изменённые лунки.
- Всё, что не похоже на зону из `PIN_ZONES`, отбрасывается при чтении
  (`normalizePinPositions`) — мусор в базе не ломает экран ввода счёта.

## Офлайн

Курс — это поле без стабильной связи, поэтому последнее сохранённое значение
кладётся в `localStorage['pestovo_pin_positions']` и читается **при загрузке
модуля**, до отрисовки шапки. Если база не ответила, игрок всё равно видит
флажок из кэша. Пришедшие из базы данные кэш перекрывают; кэш, в свою
обновлённую очередь, обновляется и админкой сразу после сохранения — так
игрок на устройстве админа видит правку даже без сети.

## Известные ограничения

- Положение флажка — грубая зона 3×3 на схеме грина, а не точные координаты:
  так админ настраивает 18 лунок за пару минут, а игрок читает картинку с
  одного взгляда.
- Панель не показывается вне экрана ввода счёта (на экране завершённого
  раунда или списка) — там она была бы лишним слоем поверх табло.
- При `prefers-reduced-motion` анимация раскрытия отключается, панель
  появляется мгновенно.
